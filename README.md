## Вопрос 5. Почему в Linux всё организовано в одно дерево от /, а в Windows есть отдельные диски C: и D:?

Linux строит систему на идее единого, логически последовательного пространства имён, где все ресурсы — файлы, устройства, процессы — подчиняются общим правилам. Windows, напротив, использует концепцию независимых логических дисков, что даёт больше гибкости в организации данных,
